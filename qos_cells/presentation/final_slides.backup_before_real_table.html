Step 3 · The quantum idea

Each record nudges a phase, then it is gone

01

Stream of records

(cell, gene, value, label): read once, never stored, zeros skipped

02

One phase gate each

All gates commute, so the register keeps only their sum

03

One measurement

A Hadamard test reads out a score: rare or common

Like rain on drums: no drum keeps a single drop, but each ends up tuned by how much fell on it.
